STUDY RPG - iPhone向けPWA

■ 主な機能
- 科目・教材・分野/章・自分で付ける問題番号で分類
- 問題一覧から個別選択、番号範囲（例：5〜10）で絞り込み
- 学習中の終了ボタン（EXP・記録は保持）
- タップで解答表示、自己採点
- 問題ごとのEXP設定、レベル、連続正解ボーナス、デイリーミッション
- アチーブメント（初正解、10/50/100問、5連続、難問突破など）
- CSV一括登録（新形式と旧形式に対応）
- JSONバックアップ・復元
- オフラインキャッシュ

■ CSV形式
新形式：subject,material,unit,number,front,back,xp
旧形式：subject,front,back,xp

■ iPhoneで使う
1. GitHub PagesなどHTTPS対応の静的ホスティングにアップロード。
2. iPhoneのSafariで公開URLを開く。
3. 共有ボタン →「ホーム画面に追加」。

■ データについて
学習データは端末のブラウザ保存領域に保存されます。Safariの履歴・Webサイトデータ削除で消える可能性があるため、定期的にSTATUSからバックアップしてください。
HPはアプリを閉じている間に裏で動くのではなく、次回起動・画面表示時に経過時間から計算します。


■ v3 変更点
- 正解ごとにEXPを即時加算・保存。途中終了しても獲得分は消えません。
- 学習画面にEXPの即時保存について明記。
- 称号を追加（勉強厨、知の狂戦士、数学の魔王、数学の神、物理の支配者、化学の錬金術師、英語の覇者など）。


■ v8 変更点
- 「わからない・復習」を選んだ問題を復習カードとして自動登録。
- 復習画面を追加し、科目・教材・単元ごとに整理。今日が復習日の問題をまとめて再出題。
- 正解・不正解の履歴に応じて復習間隔を調整（初回は翌日、正解後は3日・7日・14日・30日・60日）。
- 復習データは既存のJSONバックアップに含まれます。
- 数学・物理・化学の正解時演出は維持し、名言カードはタップするまで表示。
- 英語は1問ごとのEXP・名言ポップアップを廃止し、学習終了時に獲得EXPと正解数をまとめて表示。
- 23:00〜翌8:00はHP減少なし。修行タイマー中はHP減少を停止し、日中は60分ごとに1 HP回復（最大100）。
- アプリアイコンを紺・金を基調とした新デザインに更新。
